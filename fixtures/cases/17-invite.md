## 场景 A：码的格式和生成（R26.1）

### A-1 生成（随机数来源固定）

| 随机数（每位取的下标，0 到 30） | 存 | 显示 |
| --- | --- | --- |
| 0, 1, 2, 3, 4, 5, 6, 7 | `ABCDEFGH` | `ABCD-EFGH` |
| 30, 30, 30, 30, 30, 30, 30, 30 | `99999999` | `9999-9999` |
| 7, 20, 28, 9, 23, 30, 13, 3 | `HX7K29QD` | `HX7K-29QD` |
| 8, 22, 10, 25, 12, 26, 27, 29 | `JZM4P568` | `JZM4-P568` |

- 字符集 = `ABCDEFGHJKMNPQRSTUVWXYZ23456789`，长度 31，不含 `0`、`O`、`1`、`I`、`L`
- 用真的随机数生成 1000 个：每个都是 8 位、每一位都在字符集里

### A-2 生成撞了唯一约束（数据层）

| 情况 | 期望 |
| --- | --- |
| 第 1 次生成 `HX7K29QD`（和 I1 撞），第 2 次 `ABCDEFGH` | 存 `ABCDEFGH` |
| 连续 5 次都撞 | 报错"生成邀请码失败，再试一次"，不插入 |

### A-3 输入整理

| 输入 | 整理后 | 找码的结果 |
| --- | --- | --- |
| `HX7K-29QD` | `HX7K29QD` | I1 |
| `hx7k-29qd` | `HX7K29QD` | I1 |
| `  hx7k 29qd  ` | `HX7K29QD` | I1 |
| `HX7K--29QD` | `HX7K29QD` | I1 |
| `Hx7k-\t29Qd`（中间一个 Tab） | `HX7K29QD` | I1 |
| `HX7K_29QD` | `HX7K_29QD`（下划线不去） | 格式不对 → 不存在 |
| `HX7K-29Q` | `HX7K29Q`（7 位） | 格式不对 → 不存在 |
| `HX7K-29QDA` | `HX7K29QDA`（9 位） | 格式不对 → 不存在 |
| `HX7K-29Q0` | `HX7K29Q0`（有 `0`） | 格式不对 → 不存在（不纠正成 `O`） |
| `ZZZZ-ZZZZ` | `ZZZZZZZZ` | 格式对，没这个码 → 不存在 |
| 空字符串 | 空 | 格式不对 → 不存在 |
