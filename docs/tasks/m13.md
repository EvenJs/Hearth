## 通用要求

- **不加依赖、不改表**。骨架用 shadcn 的 `Skeleton`（`pnpm dlx shadcn add skeleton`，属于 shadcn/ui，不算新库）
- 电脑优先（1280px+）；手机 375px 不横向滚动。改完的页面两种宽度都截图看一眼
- 动到规则里的显示文字（R23.2、R24.5a），测试名带规则编号
- 每个任务只改清单里那几条，看到别的问题记下来，不顺手改

## 边界情况

- **看板默认时间段（第 4 条）**：倾向默认"最近一个有数据的完整月"（看所有账户里最晚的"数据截至"，R24.6 口径，取它所在月；那个月没过完就再往前一个月），标题旁写"数据到 MM-DD"。URL 带了时间段参数时照参数。M13-5 开始时再确认一次
- **"对比上期"在月份没过完时（第 5 条）**：不显示百分比，写"本月还没过完"
- **归属人显示名（第 16 条）**：`member.name` 是 `Male` / `Female` / `Home`，`src/lib/seed/data.ts` 和 `src/server/seed.ts` 按这个名字找人。M13-9 先查清楚有哪些代码按名字匹配，再决定是改库里的名字还是只改显示
