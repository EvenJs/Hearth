# M7：预算和税后估算（F7、F9）

> 目标：给分类设月度预算，首页顶部能看到进度和"本月还剩多少"；每人每财年填一次工资，看板上看到预计年底补税。
> 参考：`docs/prd.md` F7、F9；`docs/business-rules.md` R10、**R11**、**R14**、R16.3、R19.4；`docs/schema.md` budget、tax_profile；`docs/design/README.md`（02、10、11）
> 涉及页面或数据库的任务，先用 plan mode 说打算怎么做，我同意了再写。

## 通用要求

- **不改表、不加依赖。** `budget`、`tax_profile` M1 已经建好，`budgetProgress`（M2-11）和 `estimateHouseholdTax`（M2-12）已经有测试，复用，不另写一套
- 新的纯函数放 `src/lib/rules/budget.ts`（总览）；数据层放 `src/server/budgets.ts`、`src/server/tax.ts`；写入用 Server Actions + Zod
- 金额输入转分复用 `parseAmountToCents`（`money.ts`），显示复用 `formatAud`；日期和"本月"复用 `date.ts`、`periods.ts`
- 分类下拉复用 `category-picker`，可选范围按 R11.2（不是 R16.3 的全部）
- 全部带 `household_id`；`tax_profile.member_id` 只能是本家庭 kind = person 的 member

## 边界情况

2026-10-30 聊的时候定下来、已经写进规则的：

- 一级和它的二级可以同时设预算，总览只算最外层（R11.1）
- 还剩 = 上限合计 − 已花合计，可以是负数（R11.1）
- 没设预算的分类按一级列，部分二级有预算时列"X（其他）"（R11.1）
- 能设预算的：支出类一级、二级 + 现金支出（R11.2）
- 首页预算区块固定本月、全家，不跟筛选（R11.3）；删除预算硬删除（R11.3）
- 分类归档时预算一起删（R19.4）
- 税务卡片固定今天所在的财年；归属人筛选只影响显示哪几张（R14.6）
- 卡片"已缴" = 已代扣 + 已预缴；已预缴只读（R14.6）
- 没有税率表的财年不能整页报错（R14.7）

还没写进规则文档、先按这个做（不对就改）：

- 提醒百分比是 1 到 100 的整数，默认 80
- 编辑预算不能改分类。要换分类就删掉重建
- 预算设置页的排序：一级按 `sort_order`，二级预算排在它的一级后面；现金支出排最后
- 首页置顶条不限个数，一行放不下就换行
- Tax (ATO) 不是系统分类，没有 `systemKey`。按名字找：一级 Income 下名字是 `Tax (ATO)` 的二级（不区分大小写）。找不到（被改名了）时已预缴按 0 算，设置页提示"找不到 Income / Tax (ATO) 分类，已预缴按 0 算"
- `tax_profile` 金额 ≥ 0，已代扣 ≤ 税前总额；两个都填 0 也照样保存（等于"填过了，没有工资"，卡片不再提示去设置页）
