## M0-5 数据库连接
- [ ] 完成 🔒 M0-4

**做什么**
- 装 `drizzle-orm`、`drizzle-kit`、`@neondatabase/serverless`、`ws`
- `src/db/index.ts`：用 `drizzle-orm/neon-serverless` 和 `Pool`，**不用** `neon-http`
- `drizzle.config.ts`：schema 指向 `src/db/schema.ts`，迁移输出到 `drizzle/`
- `src/db/schema.ts` 先建空文件（下一步 Better Auth 会生成表）
- 加脚本：`db:generate`、`db:migrate`、`db:ping`（执行 `select 1` 并打印结果）

**完成标准**
- `pnpm db:ping` 连上 dev 数据库并输出成功

## M0-6 Better Auth
- [ ] 完成 🔒 M0-5

**做什么**
- 装 `better-auth`
- `src/lib/auth.ts`：Drizzle adapter（provider `pg`），只开邮箱密码登录，**关闭注册**（`disableSignUp`）
- 用 Better Auth CLI 生成 `user`、`session`、`account`、`verification` 表，放进 `src/db/schema.ts`
- 生成迁移，**先给我看 SQL**，确认后执行
- 路由处理 `src/app/api/auth/[...all]/route.ts`
- 脚本 `scripts/create-user.ts`：参数 email、name、password，在服务器端创建用户。加脚本 `user:create`
- 实现方式先查 Better Auth 当前文档（比如 admin 插件的 createUser）。**不要**为了建用户临时打开注册
- `.env.example` 和 `.env.local` 加 `BETTER_AUTH_SECRET`、`BETTER_AUTH_URL`

**完成标准**
- `pnpm user:create` 能在 dev 数据库建出用户
- 直接调注册接口返回错误

## M0-7 登录页和受保护页面
- [ ] 完成 🔒 M0-6

**做什么**
- `/login`：邮箱、密码、登录按钮。错误时显示提示，不说明是邮箱错还是密码错
- `/`：登录后才能看，显示"Hearth"和当前用户名、退出按钮
- 未登录访问任何页面（除 `/login` 和 `/api/auth/*`）都跳到 `/login`。用 Next.js 16 当前推荐的路由拦截方式，实现前先查当前文档
- 服务端也要检查 session，不能只靠前端跳转

**完成标准**
- 未登录打开 `/` 跳到 `/login`
- 登录后进 `/`，退出后回 `/login`
- 登录页电脑上居中显示，手机宽度下也能用
