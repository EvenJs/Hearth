# M7.8：装到手机主屏（PWA）

> 目标：iPhone 上"添加到主屏幕"后像一个 app 一样打开（没有地址栏），点 + 就能记一笔。只做能安装，打开时照常联网拿数据。
> 参考：`docs/roadmap.md` M7.8；`docs/prd.md` F3
> 有页面改动，先用 plan mode 说打算怎么做，我同意了再写。

## 通用要求

- **不加依赖。** 不用 `next-pwa`、`serwist` 之类的库，用 Next.js 自带的 `manifest.ts` 和 `apple-icon` 文件约定
- **不写 service worker**，不做离线、推送、后台同步
- 不碰数据库、`src/lib/` 的规则、`src/server/` 的数据层
- 名字和颜色跟现有的 `src/components/app-shell/brand.tsx`、`globals.css` 一致，不另起一套
- `globals.css` 的颜色是 `oklch`，manifest 和 `themeColor` 要换成 hex（取 `--background`、`--primary` 的浅色模式值），在代码注释里写上是从哪个变量换算的

## 边界情况

- **iOS 的登录态和 Safari 不共享**：从主屏打开要单独登录一次，之后靠 Better Auth 的 cookie 保持。这是系统行为，不用处理，验收时确认登录后能保持就行
- **proxy 拦截**：`src/proxy.ts` 的 matcher 现在只放行 `login`、`api/auth`、`_next/static`、`_next/image`、`favicon.ico`。`/manifest.webmanifest`、`/icon.png`、`/apple-icon.png`、`/icons/*` 没登录时会被跳到 `/login`，要加进放行列表。只放行这几个路径，别放宽成所有带扩展名的文件
- **没网**：打开会显示浏览器的报错页。不处理
- **standalone 没有返回键**：窄屏的导航是 `mobile-nav.tsx` 的 Sheet。确认每个页面（包括详情页、设置子页、小票核对）都有回到首页或上一页的入口，没有的列出来给我看，先不改
- 现有 `src/app/icon.png` 是 1024×1024、没有透明背景，可以直接缩成各个尺寸。iOS 会自己加圆角，图标里不要再画圆角
