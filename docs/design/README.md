## 2. 命名规则

```
<编号>-<页面>[-<状态>][-<设备>].png
```

- **编号**：两位数，按上面的页面清单
- **页面**：英文小写，`-` 连接，尽量和路由一致
- **状态**：可选，同一个页面有多种样子时才加，如 `empty`、`bulk`、`dialog-split`、`error`
- **设备**：电脑端不写；手机版加 `-mobile`
- 不用中文、空格、大写，不加日期或 `v2`、`final`（版本靠 git）
- 同一页面的不同状态共用编号，排在一起；新页面接着往后编号，不改前面的
- Stitch 里的 screen 名 = 文件名去掉 `.png`

## 3. 通用设计规则

- **电脑优先**：画板宽 1280px，可以用侧边栏、宽表格、多列看板
- 手机只要求能用：375px 不横向滚动、不报错。每个页面都出一张 `-mobile` 图当参考，但只有 `05-quick-add-mobile` 要做精细
- 导航：左侧边栏（看板、流水、导入、设置），顶栏右边有"记一笔"按钮；手机上是悬浮的 + 按钮
- 中文界面，分类名先显示英文
- 金额：`Intl.NumberFormat('en-AU', { style: 'currency', currency: 'AUD' })`
- pending 交易计入统计，但要能一眼区分：小时钟图标 + 灰色"待确认"标签，不隐藏
- 未分类：琥珀色"未分类"标签；建议转账：蓝色"建议转账"标签，旁边是"确认"和"不是"按钮
- 组件用 shadcn/ui，图表用 Recharts

## 4. 设计图和文档不一致的地方（以文档为准）

Stitch 会自己加一些需求里没有的东西。写页面时照文档做，不照图做。

### 03-transactions

| 图里有的 | 文档的规定 |
|---|---|
| 交易显示时间（`12:40`） | 交易只有日期，没有时间（schema `date`） |
| NAB 账户、"实时同步" | 只有 ANZ、ANZ Plus、CBA、现金；靠导入 CSV，不同步 |
| 原始描述里有完整账号（`12345678`） | 8 位以上数字入库前已脱敏（R2.3），显示的是 `****5678` |
| "仅 ATO 退税抵扣"筛选、"导出 CSV" | 后续功能，MVP 不做 |
| "家庭分担与对账"卡片（谁垫付、谁补给谁） | 归属人是"钱用在谁身上"，不算谁付的钱，没有这个功能 |
| "一键 AI 自动分类" | AI 功能在 MVP 之后 |

其他页面的图做到时再对一遍，发现不一致补在这里。
