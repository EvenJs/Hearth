# R13. 从手动改分类生成规则

> 业务规则的一部分，总则和索引见 [`docs/business-rules.md`](../business-rules.md)。其他规则按编号去 `docs/rules/` 找。

用户在 F8 给某笔交易改分类后，可以"存成规则"：

- 关键词默认填 merchant **去掉末尾的门店号和地名**后的部分，用户可以改（如 `COLES 0559 MELBOURNE` → 建议 `COLES`）
- 简单做法：取 merchant 里第一个纯数字词之前的部分；没有数字词就取整个 merchant
- 保存后询问是否对已有交易应用，范围按 R7.2：未分类的和 `category_source = rule` 的（2026-10-24 改，原来只写了未分类）
- 关键词已经有规则时，见 R16.6
- 保存时关键词去掉首尾空格、多个空格合成一个、转大写，最长 100 字符，不能为空（2026-10-24 补）
- 规则能指向的分类和 R16.3 的下拉一样：内部转账、归档的不能选
- 新规则 `priority = 0`、`is_system = false`
