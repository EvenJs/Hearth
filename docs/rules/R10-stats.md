# R10. 统计口径

> 业务规则的一部分，总则和索引见 [`docs/business-rules.md`](../business-rules.md)。其他规则按编号去 `docs/rules/` 找。

所有统计基于 `transaction_split`，按**交易的 `date`** 归入时间段。

| 指标     | 计算                                                                                                             |
| -------- | ---------------------------------------------------------------------------------------------------------------- |
| 收入     | Σ 拆分金额，分类 kind = `income`。包括 Tax (ATO) 的负数，所以交了税收入会变少；其中税前部分单独显示"其中税前 $X" |
| 支出     | −Σ 拆分金额，分类 kind = `expense`，**加上**系统分类"现金支出"、"银行费用"                                       |
| 不计入   | 系统分类"内部转账"（`transfer_status` 为 `auto` 或 `confirmed`）；"未分类"单独显示，不计入收支                   |
| 储蓄率   | (收入 − 支出) ÷ 收入；收入为 0 时显示"—"                                                                         |
| 分类支出 | 二级汇总到一级；退款（正数）直接冲减，所以某分类可能是负数，照实显示                                             |
| pending  | 计入统计，界面上可区分显示                                                                                       |

例子：本月 Groceries 有 −120.00 和 +0.72（退款）→ Groceries 支出 = 119.28。

"未分类"不计入收支是为了逼自己去处理它，看板上显示未分类的笔数和金额，点进去到 F8。

**已知局限**：税前收入在年底交税前会让储蓄率偏高。看板上同时显示 R14 的"预计年底补税"，自己心里有数。

## R10.1 时间段

| 选项   | 范围                                                        |
| ------ | ----------------------------------------------------------- |
| 本周   | 本周一到今天                                                |
| 上周   | 上周一到上周日                                              |
| 本月   | 本月 1 日到今天                                             |
| 上月   | 上月 1 日到上月最后一天                                     |
| 本季度 | 自然季度第一天到今天                                        |
| 今年   | 1 月 1 日到今天                                             |
| 本财年 | 7 月 1 日到今天（今天在 1 到 6 月时，从去年 7 月 1 日开始） |
| 自定义 | 用户选起止日期，含首尾                                      |

"今天"按 `Australia/Melbourne`。对比时用上一个同长度时间段（本月 1 到 21 日对比上月 1 到 21 日）。

## R10.2 汇总表

在选定时间段内，按时间粒度切分，再按一个维度分组求和。

| 参数 | 选项                             |
| ---- | -------------------------------- |
| 粒度 | 按周 / 按月                      |
| 分组 | 分类（一级，可展开二级）/ 归属人 |
| 指标 | 支出（默认）/ 收入               |

- 周从**周一**开始，到周日结束
- 时间段首尾不满一周或一个月的，只算时间段内的日子，表头标"部分"（如 `9/1–9/6 部分`）
- 每格金额按 R10 口径；行合计、列合计都显示
- 格子不跳 F8：按分类分组时，点一级那一行（名字或任意格子）展开或收起二级；其他行点了没反应（2026-10-25 改）

例子：`joint-2026-09.csv`，时间段 2026 年 9 月，按周，支出合计：

| 周                | 支出(分) |
| ----------------- | -------- |
| 9/1–9/6（部分）   | 5840     |
| 9/7–9/13          | 8580     |
| 9/14–9/20         | -705     |
| 9/21–9/27         | 21120    |
| 9/28–9/30（部分） | 10740    |
| 合计              | 45575    |

9/14 那周是负数：Medicare 报销 +45.80 大于当周支出 38.75，照实显示。

## R10.3 Top 商家（2026-10-24）

在选定时间段内，按 `transaction.merchant` 分组，**按笔数**排。

- 只看 R10 支出口径的拆分（支出类分类，加上现金支出、银行费用）
- 一笔交易算一次：先把这笔交易里命中的支出拆分加起来
  - 合计是负数（花了钱）→ 笔数 +1，金额加上它
  - 合计是正数（退款）→ 不算笔数，只冲减金额
- 笔数是 0 的商家不列（只有退款的，如 MEDICARE BENEFIT）
- 排序：笔数多的在前；笔数一样按金额大的在前；再一样按商家名字母顺序
- 显示前 5 个：商家名、笔数、金额

例子：`MELB ASIAN MARKET` 有 -62.30 和 +1.50（退款）→ 1 笔，$60.80。

## R10.4 对比上期（2026-10-24）

上期按 R10.1 的规则取上一个同长度时间段。

| 指标 | 显示 | 例子 |
| --- | --- | --- |
| 收入、支出 | 百分比变化 = (本期 − 上期) ÷ 上期，四舍五入到整数 | 上期 400.00、本期 455.75 → `+14%` |
| 储蓄率 | 百分点差 = 本期 − 上期，四舍五入到整数 | 上期 21.8%、本期 25.0% → `+3 pp` |
| 未分类 | 不对比 | |

- 上期 ≤ 0（收入、支出），或任一期储蓄率是"—"，显示"—"
- 四舍五入按绝对值，再带上符号：-12.5% → `-13%`
- 涨跌都用灰色，不用红绿（支出涨不一定是坏事）

## R10.5 近 12 个月趋势（2026-10-24）

- 固定是含本月在内的近 12 个自然月，本月只到今天。**不跟**时间段选择走
- 每月：收入、支出（R10 口径）、净额 = 收入 − 支出
- 没有数据的月份显示 0，不跳过

例子：今天 2026-10-24 → 2025-11-01 到 2026-10-24，最后一段是 2026-10-01 到 2026-10-24。

## R10.6 看板的归属人筛选和 pending（2026-10-24）

- 选了某个归属人时，看板所有区块（收入支出、分类、Top 商家、汇总表、趋势、对比上期）都只算这个归属人的拆分
- 汇总表"按归属人"分组时也照样过滤，只剩一行
- pending 交易照常计入，看板上显示"含 N 笔待确认交易"：N 是时间段内、有拆分命中当前归属人筛选的 pending 交易笔数
