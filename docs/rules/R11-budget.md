# R11. 预算

> 业务规则的一部分，总则和索引见 [`docs/business-rules.md`](../business-rules.md)。其他规则按编号去 `docs/rules/` 找。

- 预算挂在一级分类上 → 统计该一级下所有二级的支出
- 进度 = 本月该分类支出 ÷ 月度上限
- ≥ `warn_at_percent` → 黄色提醒；≥ 100% → 红色
- 只按自然月计算

## R11.1 预算总览（2026-10-30 加）

只看**本月**（今天所在的自然月，`Australia/Melbourne`），支出口径同 R10（退款冲减、pending 计入）。

| 指标 | 计算 |
| --- | --- |
| 上限合计 | Σ **最外层**预算的上限。一级和它的二级都设了预算时，二级的预算已经包含在一级里，不重复算 |
| 已花合计 | Σ 最外层预算覆盖的分类的本月支出（一级预算覆盖它所有二级） |
| 还剩 | 上限合计 − 已花合计，可以是负数。一个预算超支会吃掉别的预算的剩余 |
| 没设预算的分类 | 本月有支出、不被任何预算覆盖的部分，按一级列 |

- 二级预算（被一级包含的）照常显示自己的进度和颜色（R11），只是不进合计
- 没设预算的分类按一级列：
  - 一级和它的二级都没有预算 → 一行，金额是整个一级
  - 一级没有预算、但部分二级有 → 一行"X（其他）"，金额是没设预算的那些二级合起来
  - 系统分类现金支出、银行费用也照样列（现金支出能设预算，见 R11.2）
  - 金额是 0 的不列；负数（退款多于支出）照实列；按金额从大到小排
- 自检：已花合计 + 没设预算的分类合计 = 本月总支出（R10）
- 归档的分类不会有预算（归档时一起删，R19.4），它们的支出照常算进"没设预算的分类"

例子：只导入 `joint-2026-09.csv`（`fixtures/cases/01-joint-2026-09.md`），今天 2026-09-30。本月各分类支出：Groceries 15795、Cash withdrawal 15000、Home & utilities 9840、Entertainment & eat-out 7020（Restaurants 6120 + Bubble tea 900）、Transport & auto 2500、Bank fees 0、Personal & medical -4580，合计 45575。

场景 1：预算 Groceries 200.00、Entertainment & eat-out 100.00、Entertainment & eat-out / Bubble tea 5.00、Cash withdrawal 100.00

| 指标 | 期望(分) |
| --- | --- |
| 上限合计 | 20000 + 10000 + 10000 = 40000（Bubble tea 不算） |
| 已花合计 | 15795 + 7020 + 15000 = 37815 |
| 还剩 | 2185 |
| 没设预算的分类 | Home & utilities 9840、Transport & auto 2500、Personal & medical -4580（Bank fees 是 0，不列） |
| 自检 | 37815 + 7760 = 45575 |

Bubble tea 自己的进度：900 / 500 = 180%，红色。Cash withdrawal 150%，红色，但合计里还剩 2185。

场景 2：只有一个预算 Entertainment & eat-out / Bubble tea 5.00

| 指标 | 期望(分) |
| --- | --- |
| 上限合计 | 500 |
| 已花合计 | 900 |
| 还剩 | -400 |
| 没设预算的分类 | Groceries 15795、Cash withdrawal 15000、Home & utilities 9840、Entertainment & eat-out（其他）6120、Transport & auto 2500、Personal & medical -4580 |
| 自检 | 900 + 44675 = 45575 |

## R11.2 能设预算的分类（2026-10-30 加）

- 能设：kind = `expense` 的一级和二级（归档的除外），加上系统分类现金支出
- 不能设：收入、银行费用、内部转账、未分类
- 每个分类最多一个预算（schema 唯一约束）

## R11.3 显示位置（2026-10-30 加）

- 预算设置页（`/settings/budgets`）：完整总览（R11.1）+ 每个预算的进度
- 首页顶部：固定的预算（`is_pinned`）每个一条进度条，旁边一行"预算 $已花 / $上限，还剩 $X"（R11.1 的合计，不只是固定的那几个）
- 首页的预算区块**不跟**看板的时间段和归属人筛选走，固定是本月、全家。选了归属人时标"全家"
- 删除预算是硬删除（表里没有 `is_archived`）
